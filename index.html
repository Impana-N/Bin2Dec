How Binary to Decimal Conversion Works

Binary is a base-2 positional numeral system using only digits 0 and 1. Each position represents a power of 2, starting from the rightmost digit (least significant bit, $2^0 = 1$) and doubling with each step to the left ($2^1 = 2$, $2^2 = 4$, $2^3 = 8$, $2^4 = 16$, $2^5 = 32$, $2^6 = 64$, $2^7 = 128$).

Positional Formula: Decimal = ∑ (Digit × 2ⁿ) where n = position from right (0, 1, 2, ...)
